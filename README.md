# ほしあめ夜市

ひとり用のローグライク・ポーカー風カードゲームです。ブラウザでそのまま遊べます（ビルド不要・外部ライブラリなし）。

## 遊び方

1. `index.html` をブラウザで開く
2. 手札から最大5枚までタップ／クリックで選ぶ
3. **役を出す**で得点を稼ぐか、**捨てる**で手札を入れ替える
4. ラウンドの目標スコアに届いたらクリア。届かなければゲームオーバー
5. クリア後は夜市ショップで「おまもり」を購入できる
6. アンテは小・大・ボスの3ラウンド構成。アンテ8までクリアすると勝利

## 得点

```
得点 = (役の基本チップ + 役を構成するカードのランク値) × 倍率
```

おまもりがあると、チップや倍率がさらに増減します。画面上に `チップ × 倍率` の内訳が表示されます。

## サウンドの作り方

著作権のある音源ファイルは一切使っていません。すべて `audio.js` 内で **Web Audio API** によりリアルタイム合成しています（外部CDN・ビルドなし）。

- **効果音（jsfxr風）**: オシレーター（sine / square / triangle / sawtooth）とノイズバッファに、ADSRエンベロープ・ピッチスイープ・biquadフィルタを組み合わせて短い SE を生成
- **主な SE**: 配り／フリップ、選択・解除、捨てる、役を出す、チップの連続ティック（ピッチ上昇）、倍率ヒット、大得点ファンファーレ、ラウンドクリア、失敗／ゲームオーバー、ショップ購入・売却・リロール、ボタンホバー／クリック、おまもり発動
- **BGM**: ペンタトニック（和風寄りの音階）のメロディ＋ベース＋軽いキック／ハイハットを `AudioContext` のスケジューラで手続き生成しループ再生。ショップ中はスケールとリズムを少し変えた別曲調
- **自動再生制限**: 最初のタップ／クリック／キー操作で `AudioContext` を `resume` してから再生開始
- **音量UI**: ヘッダー右側で BGM と SE を別々にミュート／スライダー調整（SVGアイコン）。設定は `localStorage`（キー `hoshiame-audio-v1`）に保存

## 見た目・演出

ネオン夜市をイメージした暗い背景（`assets/bg.svg`）に、ピンク／シアン／紫／琥珀の発光カラーと glow（`text-shadow` / `box-shadow` / SVGフィルタ）を使っています。タイトルはネオン管風SVGロゴ（`assets/logo.svg`）です。UI・カード・おまもりはすべて手描きSVGで、絵文字は使用していません。

主な演出（CSS `animation` / `transform` / `opacity` 中心。外部CDNなし。パーティクル数は控えめ）:

- **配る**: 山札から手札へカードが飛んできてフリップ
- **選択**: ホバー／選択でカードが浮き上がり、ネオン枠が光る
- **役を出す**: 出したカードがスコア欄へ移動（色付きトレイル）→ `チップ × 倍率` がポップ／シェイク → スコアがバウンスしつつカウントアップ
- **役フラッシュ**: 役タイプごとに色の違う画面フラッシュ
- **大得点**: パーティクル・画面シェイク・ファンファーレ（DOM＋軽量 canvas）
- **ラウンド／ショップ／ゲームオーバー**: バナーやフェーズ遷移のスライド／フェード
- **おまもり**: 発動・購入時に光＋跳ね
- **ボタン**: ネオンパルス
- **背景**: 提灯のゆらぎ・きらめき・流れ星（HTML/CSS＋SVG内CSS）

`prefers-reduced-motion: reduce` ではアニメを抑え、即時反映に切り替えます。
